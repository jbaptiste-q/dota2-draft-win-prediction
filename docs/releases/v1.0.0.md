# Dota 2 Draft AI v1.0.0

`v1.0.0` covers three milestones together, not the Draft Lab product alone:
**publication** (M5–M7, the deployed product and its readiness-gate result),
**the embedding evaluation** (M8, hero interactions), and **the patch-note
labeling pipeline** (M9, semantic alignment). All three are complete.

## Included

**The product (M5–M7).** A public Draft Assistant that analyzes a completed
5v5 draft: complementary Radiant/Dire probabilities, exact additive hero
log-odds contributions, and one user-directed completed-draft replacement
comparison. The model card discloses the fit cutoff, lineage, the failed
2025-Q4 readiness gate, and the sealed 2026-Q1 test that was never opened.

**Finding: draft-only prediction (M4B).** Under this dataset, feature
contract, and temporal evaluation design, hero-identity-only draft
composition carries too little signal to beat an empirical prior on
held-out data. Development-stage gains did not survive an evaluation period
that had never influenced any modeling decision.

**Finding: hero embeddings (M8).** A low-rank pairwise-interaction model,
nine pre-registered candidates, none promoted — embeddings collapse to
within `5.6e-5` of zero at every pre-registered penalty. A descriptive-only
refit at the point they first escape zero shows no recoverable role
structure; what little signal survives concentrates on the corpus's two
most-picked heroes rather than reflecting broad interaction structure.

**Finding: patch-note semantic alignment (M9).** An acquisition →
flattening → LLM-labeling pipeline over 10,713 hero changes from official
patch notes, with a blind 120-sample model-selection evaluation (three
candidate models, model outputs withheld until human annotation was
committed) before the full pass. 10,708 of 10,713 changes labeled.
Phase 4 — the alignment analysis this pipeline was built toward — was not
run; pick-rate movement is confounded by simultaneous hero changes, counter
and partner shifts, and team-preference drift, none separable in this data.

## Evidence

- 23,123 eligible professional games in the working corpus;
- 20,087 rows used for the frozen draft-only development-candidate fit;
- 506 active offline Python tests passed;
- 10/10 Python-to-deployment parity tests passed (M7 acceptance record);
- production responses for all five public schemas matched the canonical
  local service; and
- no credential, authenticated payload, generated dataset, database,
  checkpoint, or executable model bundle is part of the release.

## Important limitations

The draft-prediction candidate is an experimental development candidate. It
did not beat the empirical-prior reference on the 2025-Q4 readiness period,
was not promoted, and did not open the sealed 2026-Q1 evaluation. The
product does not support partial drafts, next-pick recommendations, hero
ranking, bans, draft order, first pick, roles, lanes, synergy, counters, or
causal claims. Replacement comparisons are selected by the user and are not
recommendations.

The M9 pipeline produces labels, not an alignment result — Phase 4 is not
run (see the M9 milestone report).
