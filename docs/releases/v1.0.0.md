# Dota 2 Draft AI v1.0.0

The first portfolio release turns the official-Liquipedia data and modeling
pipeline into a public, end-to-end Draft Assistant:

**[Open Draft Lab](https://dota2-draft-ai.qinxuwwi.chatgpt.site/)**

> **Update:** the deployment has since moved off OpenAI Sites hosting to this
> repository's own Cloudflare account. The current live URL is
> `https://dota2-draft-lab.jbaptiste-q.workers.dev`. The link above is left
> unchanged as the historical record of the v1.0.0 release.

## Included

- completed 5v5 Radiant/Dire draft probability analysis;
- exact additive hero log-odds contributions;
- one user-directed one-for-one completed-draft comparison;
- a public model card with the fit cutoff, lineage, failed 2025-Q4 readiness
  gate, and sealed 2026-Q1 status;
- immutable official-API acquisition and provenance infrastructure;
- normalized and canonical supervised dataset contracts;
- leakage-safe temporal modeling evidence;
- a SHA-256-pinned, JSON-only inference snapshot;
- versioned FastAPI reference contracts and a golden-parity deployment Worker;
  and
- complete offline, security, and repository-hygiene validation.

## Evidence

- 23,123 eligible professional games in the working corpus;
- 20,087 rows used for the frozen development-candidate fit;
- 410 active offline Python tests passed;
- 10/10 Python-to-deployment parity tests passed;
- production responses for all five public schemas matched the canonical local
  service; and
- no credential, authenticated payload, generated dataset, database,
  checkpoint, or executable model bundle is part of the deployment.

## Important limitation

The model is an experimental development candidate. It did not beat the
empirical-prior reference on the 2025-Q4 readiness period, was not promoted,
and did not open the sealed 2026-Q1 evaluation.

This release does not support partial drafts, next-pick recommendations, hero
ranking, bans, draft order, first pick, roles, lanes, synergy, counters, or
causal claims. Replacement comparisons are selected by the user and are not
recommendations.
