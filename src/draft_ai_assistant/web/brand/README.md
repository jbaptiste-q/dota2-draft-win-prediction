from Valve's Steam content CDN:

`https://cdn.cloudflare.steamstatic.com/apps/dota2/images/dota_react/global/dota2_logo_symbol.png`

- Retrieved: 2026-08-02
- Original dimensions: 634 × 591 pixels
- SHA-256:
  `249201f03e6045e5959996a2a76e9f07b040d5e3ccf24c6ebe726e86754636ad`

The application does not recolor, crop, redraw, or geometrically transform the
logo asset. The tarot-relic treatment is implemented entirely by the
surrounding HTML and CSS frame.
